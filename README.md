# CareFlow

An open-source, multi-clinic healthcare management platform.

CareFlow aims to simplify clinic operations through appointment booking,
patient management, doctor scheduling, queue management and AI-assisted
clinical note summarisation.

## Vision

Build an extensible, secure and accessible platform that clinics can
self-host or use through a shared deployment while keeping their data isolated.

## Technology Stack

- Frontend: React, TypeScript and Tailwind CSS
- Backend: Java 21 and Spring Boot
- Database: MySQL
- AI Integration: Provider-independent architecture

## Architecture

CareFlow will initially use a modular monolith architecture.
